# REQ-05: 趣味 OSS 方針とシンプルな許容的ライセンス

ARB v2 は趣味・個人ベースの非営利 OSS として公開し、ライセンス管理の煩雑さを避けるためプロジェクト本体を `MIT OR Apache-2.0` とする。
依存ライブラリは `MIT` / `Apache-2.0` / `BSD-2-Clause` / `BSD-3-Clause` / `ISC` / `Zlib` / `CC0` / Public Domain および OS 標準 API に限定し、GPL / AGPL 依存を一切混入させない。
