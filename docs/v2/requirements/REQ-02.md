# REQ-02: 時刻不明データの隔離（unanchored サイドカー・保存/トリム共通規則）

基準軸へ対応付けられない時刻不明データ（`Unanchored`）や内外が確定しない境界データは、映像タイムラインへ混入させない。
これらは上限（件数・バイト数）付きで「時刻不明の記録」（`unanchored` サイドカー）として別枠に隔離保持し、保存とトリムで完全に同一の 3 値選別規則を適用する。上限超過時は省略件数を明示する。
