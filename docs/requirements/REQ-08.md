# REQ-08: 3 OS の結果正しさ厳格統一と PC 実機基準の性能最適化

Linux / macOS / Windows の 3 OS 間で、結果の正しさ（保存範囲、欠損・不連続表示、フレーム単位トリム精度、元データ不変保護）を厳格に統一する。
一方で再生・スクラブ・書き出しの体感性能は手元の開発 PC 実機（各 OS のネイティブ HW API 等）基準での最適化を許容し、OS 差分は `arb-os` および `arb-media` の明示的バックエンド境界に閉じ込める。
