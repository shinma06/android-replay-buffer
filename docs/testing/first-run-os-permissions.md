# 初回起動の許可（macOS / Windows）

このアプリは趣味の OSS で、有料のコード署名・公証は行っていません。そのため初回だけ OS の警告が出ます。ダウンロード元が公式のリリースであることを確認したうえで、次の手順で許可してください。

## macOS（Gatekeeper）

「開発元を確認できません」と出てブロックされたとき:

1. いったん閉じる。**システム設定 → プライバシーとセキュリティ** を開く。
2. 下の方の「"arbd" はブロックされました」の横の **このまま許可** を押し、もう一度起動して **開く**。

ターミナルで済ませる場合（ダウンロードしたフォルダで）:

```bash
xattr -d com.apple.quarantine arbd arb-cli arb-tray
```

## Windows（SmartScreen）

「Windows によって PC が保護されました」と出たとき:

1. **詳細情報** をクリック。
2. 表示された **実行** をクリック。

ブラウザやアンチウイルスが ZIP を警告する場合も、公式リリースのものなら許可して構いません。許可は初回だけで、以降は警告なしで起動します。
