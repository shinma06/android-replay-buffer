Replay clock helper is this project's Java source compiled to a deterministic DEX JAR.
Build-only: Google R8/D8 8.10.24 (BSD 3-Clause), com.google.android:android:4.1.1.4 (Apache 2.0 API stubs).
These build tools are not shipped in the plugin. Their input JAR hashes are verified by captureIdentity.
Generated replay/deps/identity.properties records source SHA, dirty flag, clock JAR and dependency hashes.
Users need only their Android SDK adb. There is no runtime download, PATH tool resolution, Python or ffmpeg invocation.
